# REDox-experiments
Code Kata with RE for .NET (practicing, exploring, experimenting, testing, and playing with structured data).

## Intro
Hands-on experiments with [REDox](https://github.com/CAPCOM-TD-OSS/REDox), a structured data engine for .NET developed by CAPCOM. This repository contains small examples to explore its APIs, test its features, and learn how it handles serialization, deserialization, and document editing
